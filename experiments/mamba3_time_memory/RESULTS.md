# Память представлений истории с адресацией по времени

<a id="time-addressed-memory-pilot"></a>

Временная адресация дала NDCG@10 = **0.0634**, индексная — **0.0626**,
модель без памяти — **0.0633**. Основной контраст time − index положительный:
**+0.0008 (+1.278%)**. Прирост относительно исходной модели составил лишь
**+0.0001 (+0.158%)**, при 76 эпохах обучения вместо 39. За первые 27 эпох обе

Проверен ограниченный пилот явной памяти причинных представлений в пределах
текущего 50-event окна, с ordinal и elapsed-time addressing controls.
Все три обучения завершены, технический и независимый terminal audit — PASS.
TEST не запускался; дополнительные seeds и варианты памяти не запускались.

## A. Что проверено

Использована прежняя MIMO dual с fixed-reference temporal calibration и общими
временными функциями двух слоёв. Encoder один раз вычисляет
`H = [h_0, …, h_(L−1)]`, форму `[B,L,64]`, после `output_norm`.
Дополнительный reader обращается к исходным причинным `h_j` из этого же forward.
Для запроса в позиции `t` доступны только valid позиции `j < t`.

`h_j` — выходное представление encoder, **не полная внутренняя SSM-матрица
`S_j`**. В архив не попадают результаты нового residual `r_j`, состояния другого
checkpoint или minibatch. Представления пересчитываются текущими весами для
переданного окна; persistent user memory и доступ к событиям за его пределами
отсутствуют. Timestamp target и время будущего запроса не используются.

Это расширение чтения истории после encoder, без изменения Mamba recurrence.
Tied item scorer, CE, разбиение данных и максимальная история 50 сохранены.
Описание конструкции и границ новизны: [DESIGN.md](DESIGN.md).

## B. Контроли и общий протокол

| Режим | Новая адресация | Параметры |
| --- | --- | ---: |
| `no_memory` | Дополнительного reader нет, точный прежний путь | 715020 |
| `index_memory` | Расстояние между позициями событий | 715021 |
| `time_memory` | Фактический прошедший интервал | 715021 |

В обоих вариантах памяти одинаковые reader, число доступных слотов и один новый
обучаемый scalar. `index_memory` сохраняет реальные gaps в MIMO dual backbone:
индексными становятся только часы нового selector. Поэтому это контроль
дополнительной временной адресации, а не полностью time-unaware модель.

Все три запуска начаты заново с seed 2026, в указанном порядке. Совпали начальные
backbone weights, общие temporal calibrators, все сохранённые RNG components,
первый TRAIN batch, data/protocol hashes, Adam и precision. Историческая
MIMO dual seed2026 воспроизведена `no_memory` точно по научной истории и SHA
checkpoint; времена и выделенная память из этого сравнения исключены. Повторный
контроль не является новым независимым seed старого исследования.

KuaiRand protocol B: 23951 пользователь, 7111 items, 1134420 взаимодействий;
TRAIN/VALID/TEST split содержит 1086518/23951/23951 взаимодействий. Оценка —
full ranking по VALID, выбор checkpoint по NDCG@10. Описанный TEST split не
означает его оценку: `test_evaluation_count = 0`, TEST loader не создавался.
Протокол — user-wise chronological leave-one-out, не global point-in-time replay.

Общие настройки: MIMO rank 4, chunk 8, два слоя, две temporal heads;
TRAIN batch 2048, VALID batch 4096, Adam LR 0.001, weight decay 0,
максимум 300 эпох, VALID каждую эпоху, прежнее раннее завершение с
`stopping_step = 10`. Использован прежний выбор последнего checkpoint при равной
округлённой лучшей метрике. Все номера эпох ниже **начинаются с нуля**.

## C. Точный дизайн

`K = 4`, фиксированные anchors `[1,4,16,32]`, `R0 = 838393 ms`.
Временные ориентиры соответствуют примерно 14, 56, 224 и 447 минутам.
Они заданы до coverage audit и не подбирались по результату.

```text
g_0 = 0; g_i = max(timestamp_i − timestamp_(i−1), 0) на valid соседях
u_t = cumulative_sum(g_0, …, g_t)                        [float64]
a_time(t,j)  = (u_t − u_j) / R0
a_index(t,j) = t − j
d(t,j,k)     = |log1p(a(t,j)) − log1p(anchor_k)|
```

Anchors обрабатываются по порядку. Каждый выбирает ближайшую ещё не выбранную
позицию `j < t`; при точном равенстве расстояний берётся наиболее поздняя.
Позиции уникальны, повтор item ID допустим. Выбранные valid позиции сортируются
перед чтением. В обоих режимах `K_t = min(4, число прошлых valid позиций)`.
Выход anchor за доступный диапазон приводит к выбору ближайшего кандидата и
отдельно учитывается в диагностике. Маска отделена от sentinel `−1`.

```text
e_tk = dot(h_t, h_jk) / sqrt(64)
w_tk = masked_softmax(e_tk)
m_t  = sum_k w_tk h_jk
r_t  = h_t + lambda m_t
lambda = tanh(beta)
```

Scores и readout вычисляются в FP32, точность backbone и BF16 kernels сохранена.
`beta` — один общий FP32 scalar, ровно ноль при инициализации, без RNG draw;
он обучается тем же Adam. Знак не ограничен. Дополнительных Q/K/V projections,
LayerNorm, time bias или regularizer нет. При пустом архиве веса и readout равны
нулю, `r_t = h_t`; padding не вносит residual. Градиенты проходят через query
и выбранные values, но не через дискретные адреса.

Dense selector имеет `O(B K L²)` операций и `O(B L²)` рабочих metadata tensors;
reader — `O(B L K D)`. Вся модель с этой обвязкой не объявляется линейной по `L`.

VALID index/time: 305826622.03 / 135045378.35 ms, то есть около 3.54 / 1.56 суток.

### Якоря вне доступного диапазона

Доля считается среди anchors, для которых ещё существует кандидат. Диапазон
берётся среди **оставшихся** позиций на соответствующем шаге жадного выбора.
Это не доля пустых слотов. Индексные и временные часы имеют разные единицы.

Сохранённые quantiles у time_memory ближе к равномерному чтению, но entropy

52428800 элементов. Не создавался банк representations `[B,L,L,D]`.
В production graph нет обучаемых Q/K/V. Dense metadata selector остаётся
квадратичным по длине истории. Между запросами representations не сохраняются.

Диагностики охватывают **последний valid query**, а не все префиксы обучения.
Counts, sums, means и extrema собирались по всем таким запросам. Quantiles
оценены по детерминированному reservoir из 256 запросов; в JSON опубликовано
8 примеров. По восьми примерам нельзя заново получить полные 256-query quantiles
или воспроизвести все elapsed-time selections без полных timestamp histories.
Полные `H`, SSM states, все query indices/weights, per-step β/λ и чистая latency
reader — `NOT_RECORDED`. Для отчёта они не восстанавливались.

## I. Научный ответ и границы вывода

В этой тройке запусков временная адресация лучше индексной: основной контраст
положителен и на полном обучении (+0.0008), и на общем горизонте 27 эпох
(+0.0002). Это пилотное наблюдение об адресации при одном и том же reader,
окне и числе параметров.

Польза добавления памяти к backbone гораздо слабее. Индексная версия ухудшила
NDCG@10 на 0.0007. Временная версия превысила no_memory всего на 0.0001 и
потребовала почти вдвое больше эпох; на первых 27 эпохах отставала на 0.0007.
Одинаковый early-stopping протокол не означает одинаковой вычислительной
стоимости. Сравнение лучших checkpoint на разных горизонтах не изолирует
эффект адресации от особенностей дальнейшей оптимизации.

Один paired seed не даёт оценки межзапусковой вариативности или статистической
значимости. Mean±std по трём разным моделям не вычисляется. Повтор no_memory
подтверждает воспроизводимость контроля, но не добавляет независимого наблюдения.
По VALID выбирались checkpoints; TEST не оценивался.

Дополнительно результат ограничен самим доступным временем: на VALID почти
89.2% временных anchors лежат вне диапазона оставшихся кандидатов, а выбранные
позиции в среднем близки к последнему событию. Нельзя приписывать выигрыш
найденным периодам интересов или точному попаданию в заданные интервалы.
Поведение других anchors, размера памяти или иной длины истории не проверялось.

Если эту линию продолжать, следующий возможный шаг — **отдельно разрешённое
multi-seed confirmation той же frozen конструкции**, без изменения anchors,
reader и протокола по итогам этого пилота. Текущего эффекта недостаточно для
замены рабочей MIMO dual. Confirmation не запущено автоматически.

Пилот не проверяет любую explicit long-term memory: только чтение причинных
`h_j` в текущем окне до 50 событий. Доступ за пределы окна, native SSM memory,
persistent state, lifelong memory и эффективный online serving остаются
отдельными задачами. Статья и Overleaf не изменялись.
