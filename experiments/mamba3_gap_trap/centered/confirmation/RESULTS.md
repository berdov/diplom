# Centered Gap-Trap: подтверждение

Устойчивое преимущество centered Gap-Trap на четырёх новых seeds не подтвердилось: две положительные и две отрицательные пары. Средняя разница VALID NDCG@10 составляет −0.000025 (−0.040%), sample std парных разниц — 0.001124. Средний эффект близок к нулю и существенно меньше разброса между seeds. Для следующего этапа сохраняется MIMO dual fixed-reference; пункт 3 завершён. Пункт 4 — временные функции отдельно по слоям — ещё не реализован и не запускался.

Лучшая эпоха centered выбрана позже fixed только в одной паре из четырёх: seed 2027, 53 против 17. В обеих выигранных парах, 2027 и 2028, положительный знак уже есть в первых 27 эпохах: +0.0003 и +0.0008. Поэтому выигрыши не возникают исключительно после более длинного обучения. На seed 2029 centered впереди в first27 (+0.0009), но уступает по итоговому максимуму (−0.0013); fixed выбрал лучшую эпоху 87 против 33. Это наблюдение о разных траекториях при одинаковом early stopping, а не доказательство причинного влияния числа эпох.

Срез first27 включает только seeds 2027–2029: centered на seed 2030 остановился после 23 эпох, полное окно 0–26 отсутствует. На трёх доступных парах средняя разница +0.000667, знаки 3/0/0. Этот неполный срез тех же запусков не заменяет основной результат четырёх пар.

Alpha в лучших checkpoints заметно различается: 0.068445 / 0.005048 / 0 / 0.013416 для seeds 2027–2030. Самая большая best alpha соответствует наибольшему выигрышу, но монотонной зависимости нет: seed 2030 с alpha 0.013416 проигрывает, а seed 2028 с меньшей alpha выигрывает. На seed 2029 best alpha равна нулю, хотя она менялась во время обучения; это не делает обученные веса тождественными fixed. Корреляционные выводы по четырём наблюдениям не делаются.
