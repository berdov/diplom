# Следующие этапы

Каждый механизм сначала проверяется отдельно. Более сложная сборка при близком
качестве не означает, что каждый её модуль улучшает качество. Первое удачное
число пилота не меняет гипотезу следующего этапа.

1. **A. Абсолютная и относительная многопериодная фаза — текущая работа.**
   Сравниваются одинаковые модули с фиксированными периодами 6 и 24 часа;
   рабочий MIMO dual остаётся дополнительным контролем. Новые признаки входят
   только в raw angles. Периоды и параметры не подбираются по VALID.
2. **B. Многомасштабное забывание — затем.** До реализации нужно выбрать
   причинную параметризацию decay, способ смешивания масштабов и контроль с
   сопоставимым числом параметров. Проверить, чем гипотеза отличается от уже
   изученных обучаемых временных масштабов. Новых запусков сейчас нет.
3. **C. Запись с учётом неожиданности — затем.** Определить неожиданность
   наблюдаемого действия относительно предыдущего состояния, не используя
   будущий target. Зафиксировать её нормировку, границы и подключение только к
   write; отделить эффект дополнительной ёмкости от содержательной гипотезы.
4. **D. Фиксация рабочей сборки.** Включать механизмы по результатам отдельных
   проверок, затем заморозить архитектуру, checkpoint, протокол и план анализа.
5. **E. TRAIN-only SVD изменений внутренних состояний.** До сбора определить
   доступ к native SSM state `S_t`, величину `ΔS_t`, оси матрицы, нормировку,
   детерминированную выборку и правило выбора ранга только на TRAIN. SVD
   выходных представлений `h_t` не заменяет анализ native состояния `S_t`.
6. **F. Подпространства и сопоставимые контроли.** Из одного исходного checkpoint
   сравнить random low-rank, SVD-init и time-dependent subspaces с одинаковым
   числом обучаемых параметров и согласованным бюджетом. Новый low-rank размер
   не равен автоматически MIMO-rank4. До кода определить, какие параметры
   обновляются и как проверяется сохранение исходной функции при инициализации.

Для B, C, E и F здесь зафиксированы только вопросы к дизайну: код и GPU-запуски
в текущий этап не входят. Статья, Overleaf и draw.io не изменяются.
