# Paper Results / опубликованный benchmark: KuaiRand Protocol B

Эта таблица содержит только опубликованные literature results. Она не смешивается с нашими experiment artifacts, потому что paper rows обычно относятся к published TEST benchmark, а новые MOO results в этой ветке являются validation-only screening.

Canonical benchmark использует 7 методов: Caser, GRU4Rec, BERT4Rec, SASRec, Mamba4Rec, SSD4Rec и TiM4Rec. Для Caser/GRU4Rec/BERT4Rec/SASRec/Mamba4Rec KuaiRand-числа взяты не из original method papers, а из SSD4Rec Table 4.

## Примечания проверки

- SSD4Rec v1 Table 4 напрямую подтверждает все шесть KuaiRand rows для Caser/GRU4Rec/BERT4Rec/SASRec/Mamba4Rec/SSD4Rec: https://arxiv.org/html/2409.01192v1 и https://arxiv.org/pdf/2409.01192v1.
- У текущего arXiv PDF v2 для SSD4Rec есть version discrepancy: финальная SSD4Rec row отличается от v1 и добавлена SIGMA baseline. Это зафиксировано как provenance note, а не смешано с canonical v1 table: https://arxiv.org/pdf/2409.01192.
- TiM4Rec Table 3 напрямую подтверждает HR/NDCG/MRR @10/@20/@50 для TiM4Rec на KuaiRand: https://arxiv.org/html/2409.16182v3 и https://arxiv.org/pdf/2409.16182.
- Machine-readable трассировка каждого числа лежит в [paper_results_provenance.csv](paper_results_provenance.csv).
